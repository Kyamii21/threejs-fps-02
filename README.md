Duskline Yard — a complete round-based tactical FPS built with three.js 0.187.0. Five Vanguard defenders hold two bomb sites against five Raider attackers in a dusk-lit container yard. First to 7 rounds takes the match (at most 13). Live-play verified: bombs planted on both sites, no console errors.

## Run it

```sh
python3 -m http.server 8080 # then open http://localhost:8080/game/index.html
```
